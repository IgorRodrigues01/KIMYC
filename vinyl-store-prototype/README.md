# Lado Sul Discoteria

Independent, static vinyl-store prototype with original brand elements and
locally generated cover illustrations. It is intentionally separate from the
REA documentation website.

Run it from this directory with `python -m http.server 4173`, then open
`http://localhost:4173`. No packages or build step are needed.

The catalog, login, registration, contact, newsletter, checkout, inventory and
shipping are demonstrations. Cart contents persist in this browser's local
storage; no personal form data, passwords, orders or payment details are sent
or stored.
